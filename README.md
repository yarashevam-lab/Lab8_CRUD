# Lab8_CRUD — Приложение для учёта студентов

## Описание
WinForms-приложение для управления списком студентов с подключением к MS SQL Server (SQLEXPRESS). Включает в себя работу с локальным репозиторием Git.

## Функциональность
- Просмотр списка студентов
- Добавление нового студента
- Редактирование данных студента
- Удаление студента
- Валидация ввода
- Обработка ошибок БД
- Логирование ошибок в файл `errors.log`
- Экспорт в CSV (из Лабы №9)

## Технологии
- C# (.NET 8)
- Windows Forms
- ADO.NET (SqlConnection, SqlCommand)
- MS SQL Server Express

## Установка и запуск
1. Откройте `Lab8_CRUD.sln` в Visual Studio.
2. Убедитесь, что установлен MS SQL Server Express и создана БД (см. Лабораторную №5).
3. Настройте строку подключения в `Form1.cs`.
4. Нажмите `F5` для запуска.

## Структура проекта
- `Form1.cs` — главная форма
- `Logger.cs` — логирование ошибок
- `Student.cs` — модель студента
- `errors.log` — файл логов
