# Проект Lab8_CRUD

Лабораторная работа №9: Работа с системой контроля версий Git.

## Описание
Приложение CRUD (создание, чтение, обновление, удаление) с функцией поиска по ФИО. 
Включает в себя работу с локальным репозиторием, ветками, слиянием и отправкой на GitHub.

## Как запустить
1. Открыть файл `Lab8_CRUD.sln` в Visual Studio.
2. Нажать `F5` для запуска.
